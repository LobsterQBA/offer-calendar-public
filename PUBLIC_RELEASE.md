# Public release boundary

This release was assembled from an explicit file allowlist in a new repository with fresh history.

Included: application source and tests, a standalone collection module with offline tests, illustrative preview records, screenshots of the synthetic local demo, and classification/schema design examples.

Excluded: original Git history, internal audits and meeting/handoff notes, cloud job exports and schedules, business findings and manifests, workbooks, production captures and screenshots, generated internal diagrams, local tool state, production logs and deployment profiles. No email recipients or production data are bundled.

Replaced: organization-specific catalog/schema names, workspace URLs, employee paths and names, application endpoints and extraction credential lookup. Live integration now requires user-supplied environment configuration. Commit attribution uses the publisher's GitHub noreply address.

Checks: offline regression tests, classification design consistency, file inventory review and pattern scans for credentials, internal endpoints, personal paths, email addresses and deployment identifiers. Pattern scans are bounded checks, not a guarantee that every possible confidential detail can be recognized.

Public provider names and website URLs are retained as collection targets. Test snippets describe commercial offer wording for regression checks; they are neither private customer records nor a verified current market inventory.

The original private repository and working files were not modified by this export.
